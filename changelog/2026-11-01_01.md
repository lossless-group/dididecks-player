# The Dididecks Player's Spec Becomes a Bundle Any Agent Can Read

## Why Care?

`dididecks-player/context-v/` holds the spec behind the package: what the viewer is, what stays in the shell, and what's next. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list what's here and what each doc is for without opening it.

## What's New?

- **The spec declares its `type`**, `Specs`, the Train-Case name of the folder it lives in.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its one folder.
- **`specs/index.md`** lists the spec with its lede.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Edits were made by hand. The doc diff is one added `type:` line. No dates moved: this is a compliance change, not a content change.
- `context-v/` isn't in the npm or JSR tarball, so nothing published changes.
